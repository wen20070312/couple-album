# 我们的相册 💕

只属于我们两个人的甜蜜小窝 —— 一个带密码保护的情侣相册网站，可以存放照片和视频。

## 功能

- 🔐 **密码保护**：进入前需输入密码（SHA-256 加密存储，不暴露明文）
- 📸 **照片墙**：网格展示所有照片，点击可放大查看
- 🎬 **视频墙**：在线播放视频
- 🕰️ **时光时间线**：按日期把照片和视频串成回忆线
- 💗 **在一起天数**：首页自动计算纪念日到今天的天数
- 🌸 **每日情话**：每天随机展示一句甜甜的话
- 📱 **PWA**：手机可「添加到主屏幕」，全屏运行像原生 App

## 如何添加照片和视频

1. 把照片放进 `media/photos/` 目录
2. 把视频放进 `media/videos/` 目录
3. 编辑 `js/media.js`，按格式登记：

```js
window.MEDIA = {
  photos: [
    { src: 'media/photos/我们的合照.jpg', caption: '第一次约会', date: '2025-05-20' }
  ],
  videos: [
    { src: 'media/videos/一起旅行.mp4', caption: '海边旅行', date: '2025-06-01' }
  ]
};
```

- `src`：文件路径（相对 index.html）
- `caption`：说明文字（可选）
- `date`：日期，用于时光时间线排序（可选）

## 如何修改密码

1. 计算新密码的 SHA-256 哈希（十六进制小写）
2. 打开 `js/config.js`，替换 `passwordHash` 的值即可

> 默认密码：`091115`

## 如何修改纪念日和情话

编辑 `js/config.js` 里的 `anniversary`（纪念日）和 `loveLines`（情话列表）。

## 部署

本项目是纯静态网站，可部署到任意静态托管（GitHub Pages / Vercel / Netlify 等），无需后端。
